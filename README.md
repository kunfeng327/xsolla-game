## 项目介绍

玩家进入异常矿区，在最长 180 秒的行动中搜集补给、消灭敌人并选择升级。撤离点开放后，可以带着已有收益离开，也可以继续挑战 Boss，争取稀有核心。只有成功撤离，背包里的全部材料才能进入营地库存。

回到营地后，材料可以兑换永久强化、武器、角色和外观。散射枪带来扇形齐射，无人机提供环绕攻击，工程师增加额外无人机与初始护盾。每次解锁，都能直接带入下一局体验。

本项目作为五人团队的四周课程项目，技术要求包含 React、Go 和 Datadog。当前仓库提供可运行的玩法基线，后续逐周接入正式在线能力。

## 快速开始

### 直接试玩

[下载单文件试玩版](https://school-gitlab.xsolla.dev/hailong_wang/starbreak-game/-/raw/main/demo/starbreak-play.html?inline=false)

下载 `starbreak-play.html` 后，用桌面版 Chrome 或 Edge 打开即可。这个文件已经内置运行代码和样式，无需安装 Node.js，也不需要附带游戏贴图。

- GitLab 文件页可能显示 HTML 源码，请先下载到电脑，再用浏览器打开。
- 每个人的试玩进度独立保存在自己的浏览器里。
- 这份 HTML 是当前源码的试玩快照。修改源码不会自动更新它。

### 运行源码

准备 Node.js 22 或 24，以及 npm。在终端执行：

```bash
git clone git@school-gitlab.xsolla.dev:hailong_wang/starbreak-game.git
cd starbreak-game
npm ci
npm run dev
```

打开终端显示的本地地址，默认通常为 `http://127.0.0.1:5173`。如果使用其他认证方式，可从 GitLab 的「代码 / Code」菜单复制对应克隆地址。

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按 `package-lock.json` 安装依赖 |
| `npm run dev` | 启动本地开发服务器 |
| `npm run build` | 执行 TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 在本地预览生产构建 |

## 游戏玩法

### 一次行动

**营地准备 → 战斗搜集 → 选择升级 → 撤离结算 → 兑换成长 → 再次出战**

| 战斗时间 | 行动节奏 |
| --- | --- |
| 0～90 秒 | 搜索补给箱、收集经验和材料，提升本局战力 |
| 90 秒 | 地图南侧撤离点开放，可以保住已有收益 |
| 120 秒 | Boss 出现，击败后保底掉落一个异常核心 |
| 180 秒 | 区域关闭，尚未撤离则行动失败 |

进入青色撤离区域后，**静止停留三秒**即可撤离。移动会重置读条，受伤不会打断。Boss 掉落的核心需要先拾取，再成功带出。

| 行动结果 | 最终收益 |
| --- | --- |
| 成功撤离 | 全部材料进入营地库存 |
| 死亡或超时 | 仅回收向下取整的 20% 合金，芯片与核心丢失 |

已解锁的武器、角色和永久强化始终保留，重新出发没有入场费。局内经验和三选一升级在行动结束后重置。

### 操作

| 输入 | 操作 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `Space` | 沿上次移动方向冲刺，获得短暂无敌 |
| `Esc` | 暂停 / 恢复 |
| 靠近补给箱与掉落物 | 自动拾取 |
| 点击升级选项 | 从三个候选中选择一项本局升级 |

角色自动攻击最近的敌人。触屏布局提供方向键与冲刺按钮，当前主要验证桌面键盘体验。

右下角的 `1× / 2× / 3×` 为演示加速，敌人和战斗计时会同时加快。首次试玩建议使用 `1×`。

### 材料与成长

| 材料 | 主要来源 | 成长用途 |
| --- | --- | --- |
| 合金 | 补给箱、敌人掉落 | 生命和拾取强化，以及大部分兑换的基础消耗 |
| 战术芯片 | 危险补给箱、精英敌人 | 解锁散射枪和环绕无人机 |
| 异常核心 | Boss 掉落 | 解锁无人机工程师和尾迹外观 |

营地现有六项兑换：**生命强化、磁力拾取、散射枪、环绕无人机、无人机工程师、星核行者尾迹**。

生命强化与磁力拾取均最多三级。当前原型的散射枪需要 **40 合金 + 2 芯片**，兑换后自动装备，下一局即可使用。初始材料为零，具体价格和成长节奏会根据试玩调整。

第一次行动可以先搜集蓝色危险补给箱获得芯片，等 90 秒后撤离，再回营地尝试兑换第一把新武器。

## 技术与代码结构

React 负责营地、HUD、升级弹层和结算。TypeScript 编写玩法和数据规则，Canvas 2D 独立更新与绘制战场，通过回调把血量、升级和结算同步给 React。营地角色与装饰由 SVG / CSS 绘制，图标使用 `lucide-react`。

```text
starbreak-game/
├── src/
│   ├── App.tsx           # 页面切换、战斗 HUD、升级弹窗和结算
│   ├── game.ts           # 游戏循环、敌人、武器、掉落与撤离
│   ├── model.ts          # 材料、配方、解锁与本地存档
│   ├── Camp.tsx          # 营地、出战配置和兑换界面
│   ├── camp.css          # 营地样式
│   ├── styles.css        # 战斗、弹层和响应式布局
│   └── main.tsx          # React 入口
├── demo/
│   └── starbreak-play.html # 可单独分发的试玩快照
├── docs/                 # 实机图片、素材说明与开发路线
├── package-lock.json
├── package.json
└── vite.config.ts
```

## 存档与验证范围

- 存档键为 `starbreak-profile-v1`。刷新后保留已经结算的材料、解锁和配置。
- 更换浏览器或访问地址后不会共享进度，清理浏览器数据会清除存档。
- 战斗中途刷新会返回营地，当前未结算物资不会入库。
- 当前客户端结算与兑换用于玩法验证。后续由 Go 校验并保存正式资产，客户端上报值不能直接作为可信奖励。
- 桌面浏览器主流程已有验证记录。触屏布局尚未在真实移动设备验证，当前版本没有音频，也未完成长期数值平衡。
- 源码中的可选 Google Fonts 加载失败时回退系统字体，单文件试玩版已移除该外部字体依赖。

已有验证情况见 [VERIFICATION.md](VERIFICATION.md)。多人、PvP、交易市场、随机装备词条、新地图和战令放在后续版本讨论。
