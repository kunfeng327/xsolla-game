录屏使用本项目实际战斗引擎，带有为讲解制作的 HUD，部分片段加速，与 React 页面布局不同。截图只裁去底部字幕区，没有重绘玩法画面。它们不能作为账号、支付或后端已经实现的证据。

游戏角色、场景、粒子和界面由本项目 SVG、Canvas 和 CSS 绘制。界面图标来自 `lucide-react`。
