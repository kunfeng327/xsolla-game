# 四周路线与验收

目标是在现有前端玩法基线上，交付支持账号存档、永久成长、Xsolla 沙箱购买、可部署和可排障的单人网页游戏。下列内容是开发计划，不表示当前已经实现。

## 第 1 周：已结算的成长可以保存

新增账号、Go 对局与资产接口，以及数据库存档。先打通散射枪的一条完整兑换路径，部署首个集成版本，并接入基础日志。

**周五验收：** 新账号完成一局撤离，材料入库，兑换并装备散射枪。重新登录后，武器与材料仍然正确，新一局能使用散射枪。同一局重复结算不会重复获得材料。

支付负责人同时确认 Xsolla 测试项目、商品配置和公网 HTTPS 回调入口。模拟支付只辅助开发，不能作为真实沙箱接入通过。

## 第 2 周：成长与沙箱购买可使用

补齐现有六项兑换与强化，统一材料兑换和支付获得的权益。接通沙箱订单、回调验签、持久化、RabbitMQ 和 Worker 发放。

**周五验收：** 使用未拥有目标权益的测试账号完成真实沙箱购买，收到可信通知后到账。在营地装备，下一局看到效果，重新登录后仍然拥有。取消支付或无效签名不发放，同一通知重复处理不重复发放。

## 第 3 周：体验打磨与故障恢复

邀请外部同学试玩，优先修复最影响首次行动与第一轮成长的问题。完善音效、反馈、材料来源说明、兑换预览和结算建议。处理并发兑换、重复请求、消息重试与异常查询。

**周五验收：** 在项目测试环境暂停 Worker，沙箱订单显示已支付、待发放。通过订单 ID、队列和 Datadog 信息定位问题，恢复 Worker 后权益自动到账，再次处理相同消息仍只发一次。监控与告警存在评估延迟，按实际配置排练。

## 第 4 周：稳定交付

冻结新功能，集中修复与调优。完成部署、初始化、接口和演示说明，固定最终版本，排练故障恢复与发布回退。

**最终验收：** 干净测试账号登录，完成战斗、搜集、撤离、兑换、换装再战和沙箱购买。已结算进度与权益可恢复，请求重试和 Worker 重启不会重复发放或留下错误余额。按文档可重新部署，不依赖临场手改数据库。

## 内容范围

一期保留一张地图、两个角色、三种武器、一个 Boss、六种局内升级、三种材料和六项兑换。优先复用现有目标追踪，完善引导与反馈。主线提前完成后，再考虑少量固定挑战记录。

多人、新地图、交易市场、随机装备词条、战令、完整实时服务端战斗与完整反作弊不列入四周承诺。存档首先保证已结算进度，战斗中断后无缝续局不作为第一期要求。
